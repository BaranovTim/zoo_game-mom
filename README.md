# Моя игра — Зоопарк

Детская игра про животных для 3–7 лет: телефон, планшет и ПК, русский и английский.
Читать ничего не нужно, всё звучит голосом.

Что есть в игре:

- **Карта зоопарка** с зонами (саванна, Азия, наш лес, Север, озеро, Австралия; тропический лес пока закрыт)
  и портретами 19 зверей. Нажал на зверя — идёшь к нему в гости.
- **Визит к зверю**: сначала кормление (перетащить нужную еду), потом одно случайное занятие, не такое, как в прошлый раз:
  - помыть губкой — стереть пятна грязи;
  - причесать щёткой — наполнить сердечки (только зверям с шерстью);
  - убрать листья в корзину — со счётом вслух;
  - уложить спать — выключить солнце и зажечь звёзды;
  - собрать пазл из картинки зверя.
- **Наклейка за каждый визит** и **альбом наклеек**: у собранных — цветной зверь, у остальных — тень.
- **Сложность** «Малыш» (3–4 года) или «Исследователь» (5–7 лет): больше пятен, листьев, звёзд, пазл 3×3 вместо 2×2.
- **Время игры** для взрослых: 10, 20 или 30 минут. Время проверяется на карте, чтобы визит к зверю не обрывался.
  Когда время вышло, в зоопарке наступает ночь, продолжить можно только через раздел для взрослых.
- Если ребёнок долго ничего не делает, рука показывает, что нажать или куда тащить.

План работ: https://claude.ai/code/artifact/2ee1af7f-0621-4246-ae68-05123d4c65ba

## Как запустить у себя

Нужен Node.js 22 или новее (https://nodejs.org, версия LTS).

```bash
npm install
npm run dev
```

Откройте адрес, который покажет команда (обычно http://localhost:5173). Адрес вида `http://192.168.…:5173` открывается
с телефона или планшета в той же сети Wi-Fi.

Другие команды:

- `npm test` — проверяет, что у всех животных есть еда, фразы и картинки, а занятия и таймер работают как задумано;
- `npm run build` — собирает игру в папку `dist/`.

## Как устроена игра

- Движок: [Phaser 4](https://phaser.io) и TypeScript, сборка через Vite. Позже та же сборка упаковывается
  в приложения через Capacitor (Android, iOS) и Tauri (Windows, macOS).
- `src/scenes/` — экраны: загрузка (`BootScene`), главный экран (`TitleScene`), карта (`MapScene`), альбом (`AlbumScene`),
  «время вышло» (`TimeUpScene`). Экраны визита к зверю наследуют общую основу `VisitScene`: вольер, кнопки,
  эмоции зверя, подсказки и выдачу наклейки. Это кормление (`FeedScene`), уход (`CareScene`: помыть, причесать,
  убрать листья, уложить спать) и пазл (`PuzzleScene`).
- `src/data/activities.ts` — какие занятия подходят зверю, выбор следующего и сколько всего в занятии на каждой сложности.
- `src/data/animals.ts` — 19 животных первой версии: зона, есть ли шерсть, правильная еда и 4 неверных варианта.
- `src/data/foods.ts` — 22 вида еды. Картинки лежат в `public/assets/foods/<id>.webp` (512 px, прозрачный фон),
  готовятся из вырезанных PNG командой `python3 scripts/prepare_art.py --food <папка food_cutout>`.
- `src/locales/` — тексты на двух языках. Источник — сценарий озвучки (`voice/build_voice.py` в файлах проекта),
  отсюда файлы не правятся вручную.
- `public/assets/animals/<зверь>/<эмоция>.webp` — картинки животных: базовая и 6 эмоций, 1024 px, плюс портрет
  `thumb.webp` 320 px для карты и альбома. Портреты грузятся сразу, эмоции — когда приходишь к зверю в гости.
  Готовятся из вырезанных PNG командой `python3 scripts/prepare_art.py <папка cutout> panda lion …`.
- Губка, щётка, листья, корзина, звёзды и сердечки нарисованы кодом в `BootScene`, файлов для них нет.
- Раздел для взрослых (шестерёнка на главном экране) закрыт примером на сложение: там язык, сложность и время игры.
- Наклейки, настройки и то, слышал ли ребёнок приветствие, хранятся только в браузере (`localStorage`), никуда не отправляются.

## Озвучка

Пока фразы читает синтез речи браузера: смотритель обычным голосом, зверь повыше. Записи из ElevenLabs
лежат в `public/audio/<язык>/<ключ>.mp3` (например `public/audio/ru/animal.panda.hello.mp3`)
и перечислены в `public/audio/manifest.json`. Фразы без записи по-прежнему читает браузер.

Озвучить все фразы через API ElevenLabs (нужны ключ и ID двух голосов из My Voices):

```powershell
$env:ELEVENLABS_API_KEY = "ключ из Profile → API Keys"
$env:ELEVENLABS_VOICE_KEEPER = "ID голоса смотрителя"
$env:ELEVENLABS_VOICE_ANIMAL = "ID голоса зверя"
node scripts/voice-generate.mjs --dry-run            # что будет озвучено и сколько символов
node scripts/voice-generate.mjs --only animal.panda  # проба: только панда
node scripts/voice-generate.mjs                      # все незаписанные фразы на обоих языках
```

Уже записанные файлы скрипт пропускает, `--force` перезаписывает их, `--lang ru` ограничивает одним языком.
Если файлы положены вручную, выполните `npm run audio:manifest`.

Игра сама начнёт играть записи вместо синтеза.
